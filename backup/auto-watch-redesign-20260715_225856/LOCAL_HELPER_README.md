# 本地助手使用指南

## 功能说明
本地助手是三谋战报系统的客户端工具，用于自动监听本地文件夹，将新增的战报截图自动上传到云端进行OCR解析。

## 系统要求
- Windows 10 或更高版本
- 网络连接（需要访问 https://api.zhenwu.fun）
- **✅ 无需安装 Node.js** - 已内置运行环境

## 安装步骤

### 1. 下载本地助手
- 从网页端点击"下载本地助手"按钮
- 或直接下载：[local-helper.zip](https://www.zhenwu.fun/downloads/local-helper.zip)
- 文件大小约 29 MB（包含完整运行环境）

### 2. 解压文件
将下载的 `local-helper.zip` 解压到任意目录，例如：
```
C:\三谋战报助手\
```

### 3. 首次配置（一键完成）
**双击运行** `启动助手.bat` 文件，首次运行会自动进入配置向导：

1. **API 地址**：直接回车使用默认值 `https://api.zhenwu.fun/api`
2. **Helper Token**：
   - 访问网页 https://www.zhenwu.fun 并登录
   - 进入"自动解析"页面
   - 点击"首次链接助手"按钮
   - 复制显示的 Token 并粘贴到命令行窗口

配置成功后会自动启动服务，显示：
```
🚀 本地助手已启动
   API: https://api.zhenwu.fun/api
```

### 4. 日常使用
每次使用时，**双击** `启动助手.bat` 即可（保持窗口打开）

### 5. 配置监听任务
1. 在网页端"自动解析"页面
2. 点击"选择同步目录"，选择截图存放文件夹（例如：`C:\Screenshots`）
3. 点击"▶ 运行"启动监听
4. 本地助手会自动监测该文件夹的新增截图并上传解析

## 常见问题

### Q1: 启动后显示"未找到配置文件"
**答**：首次运行会自动进入配置向导，按提示输入 API 地址和 Token 即可。

### Q2: 网页显示"本地助手未连接"
**答**：
1. 确认本地助手已启动（命令行窗口需保持打开）
2. 在网页端点击"刷新链接助手"
3. 如仍未连接，关闭助手窗口，重新双击 `启动助手.bat`

### Q3: Token 验证失败
**答**：
1. 确认已在网页端登录
2. 重新在网页端点击"首次链接助手"获取最新 Token
3. 删除 `local-helper.config.json` 文件，重新双击 `启动助手.bat` 进行配置

### Q4: 文件夹监听不生效
**答**：
1. 确认网页端任务状态为"运行中"
2. 确认选择的文件夹路径正确
3. 尝试在文件夹中添加一张新的 PNG/JPG 截图测试

### Q5: 重复提交已解析的截图
**答**：本地助手 v2.0 已修复此问题（自动查询后端已解析列表）。如果仍然出现，请下载最新版本。

### Q6: 如何设置开机自启动
**答**：
1. 按 `Win + R`，输入 `shell:startup`，打开启动文件夹
2. 在本地助手目录中，右键点击 `启动助手.bat`
3. 选择"创建快捷方式"
4. 将快捷方式移动到启动文件夹

## 文件说明
- `nodejs/` - Node.js 运行环境（已内置，无需安装）
- `local-helper.js` - 主程序
- `启动助手.bat` - 一键启动脚本（**推荐使用**）
- `README.md` - 详细说明文档
- `local-helper.config.json` - 配置文件（首次运行后自动生成）
- `local-helper.state.json` - 状态缓存（已处理文件记录）

## 数据安全
- 本地助手仅上传您选择的截图文件夹中的图片
- Token 仅用于认证，存储在本地配置文件中
- 所有数据传输使用 HTTPS 加密
- 不会上传任何系统文件或个人数据
