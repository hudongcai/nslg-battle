# 本地助手

这是战报自动监听的本地助手。它运行在用户自己的电脑上，负责持续监听截图文件夹；网页负责创建任务、查看进度和查看结果。

## 使用流程

1. 在网页里创建解析任务。
2. 点击“连接本地助手”，复制连接码。
3. 首次安装后，先执行一次 `local-helper/install-local-helper.bat`。
4. 安装完成后，可以双击桌面上的 `Zhenwu Local Helper`，也可以直接在网页点击“打开本地助手”。
5. 在助手窗口里粘贴连接码，点击“连接助手”。
6. 在任务列表里选中任务，点击“为选中任务选择文件夹”。
7. 选完截图目录后，助手会在后台持续监听新增图片。
8. 直接点窗口右上角关闭，只会隐藏到后台；要彻底退出，请在托盘菜单里点“彻底退出”。

## 启动方式

推荐用户双击：

```text
local-helper/start-local-helper.vbs
```

兼容入口：

```text
local-helper/start-local-helper.bat
```

开发调试：

```bash
node local-helper/local-helper.js
```

## 当前行为

- 默认连接本机 `http://127.0.0.1:3000/api`
- 助手窗口负责连接账号、刷新任务、选择文件夹
- 后台进程负责持续轮询任务并自动上传新增截图
- 目录绑定、任务进度、错误状态会回写到网页任务列表
- 打包时会带上 `node.exe`，用户侧不需要额外安装 Node

## 关闭说明

- 点击窗口右上角关闭：隐藏到后台
- 托盘菜单“彻底退出”：真正结束程序和后台监听
